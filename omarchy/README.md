# Neon Mary: Blade Runner Omarchy themes

Neon Mary is the theme family; `neon-mary-{dark,light}` are the Blade Runner variant's native packages. Each package contains `colors.toml`, `icons.theme`, and all generated background variants. Copy one into `~/.config/omarchy/themes/` and apply with `omarchy-theme-set neon-mary-dark`.

`omarchy/generated/` contains portable downstream resource snapshots for the supported terminal/editor targets.
