# Neon Mary: The Crow (1994)

Neon Mary is the theme family; `neon-mary-crow-{dark,light}` are the gothic Crow (1994) variant's native Omarchy packages. `apply-crow.sh` installs the selected package, applies the 4K wallpaper, refreshes shell IPC, and enables the transparent top bar.

```sh
./omarchy/apply-crow.sh dark
```
